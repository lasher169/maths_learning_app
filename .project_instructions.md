# MathMentor - Adaptive Maths Learning Platform

## Overview
An adaptive mathematics learning webapp for Australian students (Years 1-12). AI-powered question generation with adaptive difficulty, instant feedback, and performance tracking.

## Tech Stack
- React 18 / Next.js 14 (App Router)
- Prisma ORM with PostgreSQL (Supabase for user's self-hosted deployment)
- NextAuth.js v4 for authentication
- Abacus.AI LLM API (gpt-5.4-mini) for question generation and answer evaluation
- Tailwind CSS with design token system

## Design
- **Primary**: Purple (262 83% 58%) - consistent across all accent elements
- **Fonts**: DM Sans (body), Plus Jakarta Sans (display), JetBrains Mono (numeric/code)
- **Style**: Clean, modern, card-based UI with subtle shadows and framer-motion animations
- **Layout**: Max 800px for practice/results, 1200px for dashboard/students

## User Roles
- **STUDENT**: Practice sessions, view own performance
- **TEACHER**: Monitor assigned students' progress, add students by email

## Key Features
- Adaptive difficulty (1-5 scale): increases after 2 consecutive correct, decreases after 2 consecutive wrong
- Streaming LLM responses for question generation and answer evaluation
- Timed sessions (5/10/15/20/30 min)
- End-of-session review with detailed feedback
- Topic selection based on Australian curriculum per year level

## Database Schema
- User (with role, teacherId for teacher-student relationship)
- PracticeSession (yearLevel, topic, duration, scores)
- Question (questionText, correctAnswer, difficulty)
- StudentAnswer (answerText, workingShown, marks, feedback)
